AgentHub

Specialized agents for your own software.

The general Compass agent does not automatically know the details of every engineering application, company standard, or workflow. With AgentHub, you can create that missing knowledge for your own case, save it, and share it with your team or anyone who needs an agent that understands the software the way an expert user does.

For experts

Who should build specialized agents?

The best agents start with people who already know the work: what the software is used for, which steps matter, where mistakes happen, and what a good result looks like.

Software vendors

Give users an assistant that understands the workflows inside your product instead of leaving them with generic help text and long manuals.

Engineering teams

Package internal methods, project standards, and repeated tool sequences so engineers spend less time retracing the same setup steps.

Expert users

Turn hard-earned knowledge of a niche application into an agent that can guide others through the same software with more confidence.

Consultants

Carry repeatable workflows across projects, clients, and specialized desktop tools without starting from scratch each time.

The knowledge

What information do you teach the agent?

AgentHub is not about training a new foundation model from scratch. It is about giving Compass the software-specific context it needs: what to look at, what steps to follow, what language to understand, and which automation paths are available.

Important screens and controls

Menus, dialogs, buttons, panels, and visual states that matter for the workflow. The agent learns where the work happens and what the screen means.

Repeated task sequences

The steps experts perform again and again inside the application. These examples become reusable operating knowledge instead of one-off instructions.

Domain vocabulary

Terms, documents, naming conventions, and project language the agent should understand for that tool and discipline.

Automation hooks

Optional scripts, APIs, file formats, or command paths when the software exposes them. This lets Compass combine screen operation with faster direct automation.

How it works

One expert teaches once. Everyone benefits.

You show AgentHub the workflow, package the knowledge around that workflow, and share the resulting agent. Other users can then import it and benefit from the same software-specific knowledge.

01 Capture examples

Record the screens, controls, files, and examples that define how the task is done in the real application.

02 Package context

Save UI templates, workflow examples, documentation, prompts, and optional automation hooks that guide the agent.

03 Share and reuse

Export the agent so teammates, customers, or other experts can import it and work with the same specialized knowledge.
